# Week 2 – Full Stack Web Development (MERN)

This folder contains the Week 2 learning materials for the Full Stack Web Development (MERN) program. It covers backend development with Node.js, Express.js, and MongoDB, along with a React fundamentals practice set.

## Topics Covered

### Backend Development
- Node.js basics and NPM setup
- Express.js framework and routing
- MongoDB and Mongoose for database management
- REST API design principles
- Authentication using JWT and bcrypt

## Assignments

### 1. To-Do List REST API
- Create endpoints to add, update, and delete tasks.
- Use MongoDB for data storage.
- Test the API using Postman.

### 2. User Authentication API
- Build routes for user registration and login.
- Implement password encryption.
- Add JWT-based authentication.

## Mini Project: Notes App Backend

Develop a backend API for a notes-taking application.

- Implement CRUD operations for notes.
- Secure routes using JWT authentication.

**Learning outcome:** Understand backend logic, database integration, and API creation for real-world applications.

## React Fundamentals – Practice Set

The Week 2 practice set also includes these React exercises:

1. Create a React component that displays product information.
2. Implement props and state in a component.
3. Create a To-Do app with add and delete functionality.
4. Use React Router for multi-page navigation.
5. Add CSS Modules for component styling.

## Materials Included

- **Runtime:** Node.js
- **Backend framework:** Express.js
